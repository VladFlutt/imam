# Каталог халяль-мест

`catalog.json` — проверенные модератором места. Приложение берёт свежую версию
из ветки `main` на GitHub (raw.githubusercontent.com), а если сети нет — копию из
сборки. Поэтому изменения каталога попадают к пользователям без новой версии
приложения.

Как пополняется каталог:

1. Пользователь нажимает на карте «Предложить место» или «Сообщить об ошибке».
2. Заявка приходит issue в репозиторий (через сервер помощника, `worker/`, или
   по ссылке на форму GitHub).
3. Модератор проверяет место и сертификат (звонок, сайт органа сертификации,
   фото сертификата) и добавляет запись в `catalog.json` через pull request.

Не добавляйте место без проверки сертификата: в каталоге только то, что
подтверждено.

## Формат записи

```json
{
  "id": "msk-0001",
  "kind": "halal",
  "name": "Название",
  "lat": 55.75, "lng": 37.61,
  "address": "ул. Примерная, 1",
  "hours": "Mo-Su 10:00-22:00",
  "osm": "node/123456",
  "certificate": {
    "issuer": "Орган сертификации",
    "number": "№ ...",
    "until": "2027-06-30",
    "url": "https://..."
  },
  "checked": "2026-11-04"
}
```

`kind`: `halal` (магазин, кафе, ресторан) или `mosque`. `osm` — необязательная
ссылка на объект OpenStreetMap: такая запись заменяет его на карте.
`hours` — в формате OSM `opening_hours`.
