# Имам — справочник мусульманина

Бесплатное приложение для мусульман России и СНГ: время намаза, Кибла, Коран с переводами, календарь хиджры с памятными датами, дуа и азкары, карта мечетей и халяль-мест, ИИ-помощник, который отвечает только по аятам Корана.

Подход нейтральный суннитский, без политики и полемики. Приложение не собирает личные данные: настройки, закладки и история чата хранятся на устройстве.

Концепция и обоснование решений: [Имам: концепция приложения](https://claude.ai/artifact/WnAiwf6uEBAJy99UntkkfY).

## Состав репозитория

| Папка | Что внутри |
| --- | --- |
| `app/` | Приложение на Flutter (iOS, Android, веб) |
| `worker/` | Сервер ИИ-помощника на Cloudflare Workers (бесплатный тариф) |

## Языки

Интерфейс: русский, английский, арабский (RTL), татарский, узбекский, казахский, кыргызский, таджикский, азербайджанский.

Переводы Корана: Э. Кулиев (рус.), Saheeh International (англ.), Якуб ибн Нугман (тат.), Мухаммад Содик Мухаммад Юсуф (узб., кириллица), Абдулмухаммад Ояти (тадж.), Мамедалиев и Бунятов (азерб.). Для казахского и кыргызского свободного перевода в открытых источниках не нашлось, пока показывается русский. Советы и хадисы дня, дуа и описания памятных дат переведены на все девять языков (`app/lib/data/content_cis.dart`); переводы на языки СНГ ждут вычитки носителями.

## Компас и уведомления

- Экран Киблы на телефоне поворачивает циферблат по датчику ориентации (`flutter_compass`), вибрирует и пишет «Вы смотрите на Киблу», когда отклонение меньше 5°. В браузере остаётся направление от севера.
- Напоминания о намазе (`flutter_local_notifications`) включаются в настройках, планируются на 30 дней вперёд (на iOS на 12 из-за лимита в 64 уведомления), за день до конца срока напоминают открыть приложение, обновляются при запуске и смене города, метода или мазхаба. На Android запрашиваются разрешения на уведомления и точные будильники.

## Запуск приложения

```bash
cd app
flutter pub get
flutter run                      # телефон или эмулятор
flutter run -d chrome            # веб
flutter build web --release --no-web-resources-cdn \
  --dart-define=AI_ENDPOINT=https://imam-ai.ACCOUNT.workers.dev
```

Без `AI_ENDPOINT` помощник работает в офлайн-режиме: фильтрует вопрос и показывает подходящие аяты, но не формулирует ответ.

## Сервер ИИ-помощника

```bash
cd worker
npm install
npm test                                   # проверки фильтра и цепочки моделей
npx wrangler login
npx wrangler secret put GROQ_API_KEY        # бесплатный ключ: console.groq.com
npx wrangler secret put OPENROUTER_API_KEY  # бесплатный ключ: openrouter.ai
npx wrangler deploy
```

### Выкладка из GitHub без командной строки

Workflow `.github/workflows/worker.yml` проверяет и выкладывает сервер при каждом изменении `worker/` в `main` (или вручную: Actions → AI worker → Run workflow). Нужно один раз добавить секреты в **Settings → Secrets and variables → Actions**:

| Секрет | Обязателен | Где взять |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | да | dash.cloudflare.com → My Profile → API Tokens → шаблон «Edit Cloudflare Workers» |
| `CLOUDFLARE_ACCOUNT_ID` | да | dash.cloudflare.com → Workers & Pages, справа «Account ID» |
| `GROQ_API_KEY` | нет | console.groq.com → API Keys (бесплатно); без него отвечает встроенная модель Cloudflare |
| `OPENROUTER_API_KEY` | нет | openrouter.ai → Keys (бесплатные модели `:free`) |
| `IMAM_ISSUES_TOKEN` | нет | github.com → Settings → Developer settings → Fine-grained token на этот репозиторий с правом Issues: Read and write; нужен для заявок на места |

После первой выкладки адрес сервера (`https://imam-ai.<ваш-поддомен>.workers.dev`) виден в логе шага «Выкладка на Cloudflare». Его нужно записать в переменную репозитория `AI_ENDPOINT` (Settings → Secrets and variables → Actions → Variables): с ней собираются APK.

Модели пробуются по очереди: Groq, затем бесплатные модели OpenRouter, затем Cloudflare Workers AI (работает без внешних ключей). Названия моделей задаются в `wrangler.toml`. Поиск аятов делается на телефоне, сервер получает только текст вопроса и найденные аяты, а модели разрешено ссылаться только на них; лишние ссылки вырезаются. Словарь запретных слов и тем общий для приложения и сервера: `app/assets/ai/blocklist.json`.

## Хадисы и каталог халяль

- Раздел «40 хадисов ан-Навави» (Ещё → 40 хадисов): арабский текст, перевод, источник. К хадисам 8, 14 и 29 добавлены пояснения классических комментаторов, чтобы их не вырывали из контекста.
- Каталог халяль-мест: на карте места из `app/assets/halal/catalog.json` отмечены зелёной галочкой, в карточке — орган сертификации, номер и срок действия; просроченный сертификат помечается. Приложение загружает каталог из `main`, так что новые записи доходят до пользователей без обновления приложения. Кнопка «Предложить место» и «Сообщить об ошибке» создают issue с меткой `halal-place` (через сервер помощника или форму GitHub).

## Источники данных и лицензии

- Коран: арабский текст Uthmani и переводы — [Tanzil](https://tanzil.net), через npm-пакеты `quran-json` (CC BY-SA 4.0) и `@ghoran/translation`. Переводы Tanzil разрешены к некоммерческому использованию без изменений; перед коммерческим релизом нужно уточнить права.
- Время намаза: [adhan_dart](https://pub.dev/packages/adhan_dart) (MIT), метод ДУМ РФ (16° / 15°) по умолчанию, ханафитский аср, правило седьмой части ночи для северных широт.
- Календарь хиджры: Умм аль-Кура, пакет [hijri](https://pub.dev/packages/hijri) (MIT). Даты могут отличаться на день от объявлений ДУМ.
- Мечети и халяль: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL, через Overpass API.
- Шрифты: Amiri Quran, Amiri, Noto Naskh Arabic, Noto Sans (SIL OFL).
- 40 хадисов ан-Навави: арабский текст — npm-пакет `@kazishariar/nawawi-40-hadith-data` (CC BY 4.0). Английский перевод из пакета повреждён (вырезаны фрагменты), поэтому переводы на русский и английский подготовлены заново с арабского и ждут проверки имамом.
